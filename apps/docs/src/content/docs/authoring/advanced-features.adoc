== Math

Math is rendered to static HTML at build time with KaTeX, so pages carry no math JavaScript. The `+stem:[]+` macro and `+[stem]+` block use AsciiMath; the `+latexmath:[]+` macro and `+[latexmath]+` block use LaTeX.

Inline AsciiMath: stem:[sqrt(x^2+y^2)]. Inline LaTeX: latexmath:[\frac{a}{b}].

[stem]
++++
sum_(i=1)^n i = (n(n+1))/2
++++

[latexmath]
++++
\int_0^1 x^2\,dx = \frac{1}{3}
++++

[source,asciidoc]
------

== Images

Images scale down to the reading column. Relative paths resolve against the site root, so keep image files in the site's `public/` folder. Set `:imagesdir:` in a document to use another base path.

== Code Callouts

Number markers at the end of a line become badges in the highlighted code. The numbered list below the block explains each one, and the copy button copies the code without the markers.

[source,typescript]
----
const app = createApp(); // <1>
app.use(router); // <2>
----
<1> Create the application instance.
<2> Register the router.

== Includes

Use `include::` with a path relative to the current file. Files and folders whose name starts with `_` are partials: they are never published as pages, and editing one reloads the pages in dev. Included files must sit in the page's folder or below it.

include::_partials/include-demo.adoc[]
