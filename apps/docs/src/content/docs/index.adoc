= Olympia Documentation Theme
:description: A technical documentation and API reference theme for Astro 5 with native AsciiDoc support, build-time syntax highlighting, and full-text search.
:category: Getting Started
:order: 1
:badge: CORE
:badge-variant: primary

**Olympia** is a technical documentation theme built for **Astro 5**. Write standard **AsciiDoc (`.adoc`)** files and Olympia automatically parses document attributes, generates a structured sidebar tree, extracts table-of-contents headings, and compiles dual-theme syntax-highlighted code blocks with full-text search indexing.

[TIP]
.Quick Search Shortcut: kbd:[Cmd+K] / kbd:[Ctrl+K]
====
Press kbd:[Cmd+K] (or kbd:[Ctrl+K] on Windows and Linux) anywhere on the page to open the command palette and search across document titles, headings, and API endpoints.
====

== Key Features

[cols="1,3",options="header"]
|===
| Feature | Description

| **Native AsciiDoc Content Loader**
| Loads `.adoc` files directly via Astro's Content Layer (`asciidocLoader`), with support for live hot-reloading (HMR), AsciiDoc Document Header attributes, and optional YAML frontmatter.

| **Three-Column Reference Layout**
| Persistent left navigation tree (with collapsible groups and HTTP method badges), a wide central reading canvas, and a scroll-synced right table of contents that adapts into a slide-out drawer on mobile viewports.

| **Semantic Callout Admonitions**
| Automatically transforms AsciiDoc `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, and `CAUTION` blocks into semantic callout containers with status icons.

| **Build-Time Shiki Highlighting**
| Pre-renders dual-theme syntax highlighting (`github-dark-default` and `github-light-default`) with zero client-side syntax runtime, complete with filename headers, HTTP endpoint pills, and one-click copy buttons.

| **Interactive Tab Blocks (`[tabs]`)**
| Turns standard AsciiDoc `[tabs]` blocks into accessible, keyboard-navigable tab panels for multi-language code examples or platform instructions.

| **Full-Text Search & Theme Toggle**
| Built-in Pagefind static full-text indexing paired with a native `<dialog>` command palette and a zero-FOUC dark/light color scheme switcher.
|===

== Quick Start

=== 1. Common Commands

Run the following commands from the repository root using **Bun**:

[tabs]
--
.Development Server
[source,bash]
----
# Install workspace dependencies
bun install

# Start the local dev server with HMR (http://localhost:4321)
bun run dev
----

.Production Build & Search Index
[source,bash]
----
# Build static HTML and generate the Pagefind search index
bun run build

# Preview the production build locally
bun run preview
----

.Unit Tests
[source,bash]
----
# Run AsciiDoc loader and converter test suites
bun test
----
--

=== 2. Configure the Content Layer

Register `asciidocLoader` from `@olympia/theme/loader` in your Astro project's `src/content.config.ts`:

[source,typescript,filename="src/content.config.ts"]
----
import { defineCollection, z } from 'astro:content';
import { asciidocLoader } from '@olympia/theme/loader';
import { BADGE_VARIANTS, DEFAULT_CATEGORY, DEFAULT_ORDER } from '@olympia/theme';

const docs = defineCollection({
  loader: asciidocLoader({ base: './src/content/docs' }),
  schema: z.object({
    title: z.string(),
    description: z.string().default(''),
    category: z.string().default(DEFAULT_CATEGORY),
    order: z.number().default(DEFAULT_ORDER),
    badge: z.string().optional(),
    badgeVariant: z.enum(BADGE_VARIANTS).optional(),
    httpMethod: z.string().optional(),
    endpoint: z.string().optional(),
    attributes: z.record(z.string(), z.string()).default({}),
    headings: z
      .array(
        z.object({
          depth: z.number(),
          slug: z.string(),
          text: z.string(),
        }),
      )
      .default([]),
  }),
});

export const collections = { docs };
----

[IMPORTANT]
====
Keep the `headings` field. The loader fills it and the on-page table of contents reads it; a schema without it renders an empty table of contents.
====
